# NV3 - ValidateName

ValidateName: Our Name Validation 3 service uses machine learning to assess and classify input names. Will validate and score, as well as analyze for negative sentiment and classify the input to distinguish between names and other types of inputs like business, dictionary, or garbage.

## [ValidateName Developer Guide/Documentation](https://www.serviceobjects.com/docs/dots-name-validation-3/nv3-operations/nv3-validatename/)
